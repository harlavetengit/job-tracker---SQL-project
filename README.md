# Job Application Tracker — SQL Learning Project

A small personal SQL project built while actively job hunting.

I have a background working with big data from my physics studies but never properly learned SQL.
This project is my way of learning it through a real, everyday context while tracking my own job applications.

## What I did
- Tracked job applications in Excel
- Designed a simple SQLite database schema to store the data
- Wrote SQL queries to analyse my job search

## What the queries cover
- Viewing all applications sorted by date
- Counting applications per status
- Filtering active applications still in play
- Calculating rejection rate
- Average days to rejection
- Applications per company
- Applications submitted per week
- Jobs saved but not yet applied to

## Tools used
- SQLite
- DB Browser for SQLite
- VS Code

## Status
Ongoing — actively updated as my job search continues.
